# 参考模板实测规格（assets/template.pptx）

本文件是 `assets/template.pptx` 的实测说明书，也是 `scripts/build_ppt.py` 的行为契约。
生成 PPT 前必读；改动模板或脚本时同步改本文件。

所有数值都是从模板 XML 里量出来的，不是估的。单位：厘米（1 cm = 360000 EMU）。

## 一、模板概况

- 画布 33.87 × 19.05 cm（16:9 宽屏），共 16 张幻灯片蓝图。
- 第 2–16 张统一套用自定义版式 `10_自定义版式`：深色背景图、右上角 ISCAS 标识、
  右下角自动页码 `‹#›` 都由**版式**提供，幻灯片本身不含这些元素——所以正文页只需填
  标题、图表、要点、总结四个槽位。
- 第 1 张（封面）套用版式 `标题幻灯片`，含居中大标题与副标题占位符。
- 幻灯片母版标题样式：微软雅黑 + Times New Roman，28 磅加粗，白色。
- 配色为 Office 标准主题色（accent1 `#5B9BD5`、accent2 `#ED7D31`、accent5 `#4472C4`、
  accent6 `#70AD47`、accent4 `#FFC000`、accent3 `#A5A5A5`、dk2 `#44546A`）。
  图表由 `scripts/shapes.py` 按这套主题色生成 PPT 原生形状（原图按位图嵌入），不要引入模板外的配色。
  详见 `references/figure-spec.md`。

## 二、页面蓝图（kind → 模板页）

脚本按 `kind` 取蓝图，再重新生成该页 XML。同一 `kind` 的页可以无限复用，
所以研究内容有几项都不需要改模板。

| kind | 模板页 | 版式 | 用于 |
|---|---|---|---|
| `cover` | slide1 | 标题幻灯片 | 封面 |
| `accumulation` | slide2 | 图表在左（大）、文字在右、总结通栏 | 第 2 页 编译领域积累（核心考核页） |
| `text-left` | slide3 | 文字在左、图表在右 | 第 3 页 需求分析、第 4 页 研究现状 |
| `figure-left` | slide5 | 图表在左、文字在右 | 第 5 页起的所有正文页（概述、内容、路线、指标、成果、周期、经费） |
| `closing` | slide16 | 总结 + 感谢语 + ISCAS 标识 | 结束语 |

模板里 slide 6–15 与 slide 5 几何完全相同，slide 8/9/10/11 是「研究内容三、技术路线三」，
脚本不区分它们，一律用 `figure-left` 蓝图重新生成。

## 四、字体与字号

字号**不固定**。族名跟模板，磅值按槽位几何和实际字数由脚本计算。族名不许改。

| 位置 | 中文字体 | 西文字体 | 基准 / 范围 | 其他 |
|---|---|---|---|---|
| 页面标题 | Microsoft YaHei（微软雅黑） | Times New Roman | 基准 28 磅，超长 24 / 20 | 加粗、白色（bg1） |
| 封面标题 | **微软雅黑** | Microsoft YaHei | **默认 44 磅**；标题过长时降到 40 / 36 / 32 | 居中（脚本显式写 algn="ctr"）、关 `spAutoFit` |
| 封面副标题 | 主题字体 | — | 24 磅 | 居中 |
| 封面右下角 | 楷体 | Times New Roman | **报告人/日期 20 磅，单位行 18 磅** | 脚本显式设定，并加宽加高文本框。12 磅在投影上读不清，不许再降 |
| 图内文字 | 楷体 | — | **16–18 磅**（下限 14） | 图里的文字是真文本，`sz` 直接写磅值 |
| 正文要点 | 楷体 | Times New Roman | **默认 16，按框适配 12–18** | 标签带下划线 `u="sng"`，项目符号 Wingdings |
| 正文首行（标题行） | 楷体 | Times New Roman | 正文字号 + 2 磅，不超过 18 | 只在给了 `heading` 时出现 |
| 底部总结 | 楷体 | Times New Roman | **默认 16，按框适配 12–16** | 总结框只有一行高（1.13 cm），下面紧挨页码框，**不能往下加高**；总结句要写成一句话、一行放下（16 磅约 52 字）。压到 14 磅以下说明太长，回去改短 |
| 结束语收尾句 | 楷体 | — | 24 磅 | 加粗 |
| 感谢语 | 华文中宋 | — | 36 磅 | — |
| 图表槽 | 楷体 | — | 由 `shapes.py` 决定 | 成品是一组原生形状（可编辑），不再写「图/表」 |

适配算法（`fit_font_pt` + `align_body_and_figure`）：

1. **正文框与图表槽垂直对齐。** 模板正文框比图表槽更靠下、更矮
   （text-left 上沿差约 2 cm，figure-left 差约 2.5 cm），直接填会一边高一边矮。
   脚本把正文上沿抬到图表槽上沿（4.74 cm），下沿收到总结框上方 0.3 cm。
   text-left 的正文右沿会压进右侧图表约 1 cm，对齐高度后必须把正文宽收到
   图表左沿之前 0.4 cm，否则文字盖住图。
   figure-left / accumulation（图在左、字在右）把正文左沿改为「图右沿 + 间隙」
   （accumulation 1.2 cm，figure-left 2.0 cm）。模板原本把正文放在 23.06 cm，
   离图 4 cm，中间空一大条。
2. 从默认磅值往下试到下限，使「行数 × 行高」不超过对齐后的框高。CJK 计 1 字宽，ASCII 计 0.55。
3. 关 `spAutoFit`，避免 PowerPoint 再偷偷缩放一次。
4. 投影可读下限是 12 磅。12 磅仍溢出 → 减要点，不要再降。
5. 封面「报告人 / 单位 / 日期」三行：报告人与日期 20 磅、单位行 18 磅，
   文本框加宽加高到 11.40 × 3.35 cm，不再用模板的 12 磅小框。

## 五、字数上限（建议，溢出靠降字号消化）

正文框宽 9.89 cm。16 磅时每行约 16 个汉字、扩展后约 10 行。这是**建议密度**，
不是硬截断：超了脚本降字号，并打 `[校验]` 提示回去改内容。

| 项 | 建议上限 | 依据 |
|---|---|---|
| 每页要点条数 | 6 条 | 第 2 页允许 6，其余页 3–5 |
| 每条要点字数 | 28 字 | 16 磅约两行；更长就降到 14 / 12 磅。**研究现状页放宽到 44 字**——那页要写清「现状原理 + 对应不足」 |
| 底部总结句 | 52 字 | 总结框只有一行高，16 磅一行约 52 字；写不下就降字号，压到 14 磅以下要改短 |
| 封面标题 | 每行 16 字 | 44 磅 + 25.4 cm 宽；超长由脚本降到 40 / 36 / 32 磅 |
| 正文字号下限 | 12 磅 | 再小后排看不清 |

`build_ppt.py` 会打印每页实际字号、要点条数/字数、总结字数、旁白字数。

## 六、内容 JSON 契约

```json
{
  "title": "项目全称（写入 docProps/core.xml）",
  "pages": [ ... 按放映顺序排列，第 1 页必须是 cover，最后一页是 closing ... ],
  "narration": { "1": "第 1 页旁白", "2": "第 2 页旁白" }
}
```

`narration` 也可以用数组（按页序对应），或整个省略。

各 `kind` 的字段：

| kind | 必填 | 选填 |
|---|---|---|
| `cover` | `title` | `subtitle`、`presenter`、`date`、`org`（默认「中国科学院软件研究所」） |
| `accumulation` / `text-left` / `figure-left` | `title` | `heading`、`points`、`summary`、`figure` |
| `closing` | — | `title`（默认「结束语」）、`summary`、`thanks`（默认「感谢各位评审专家！」） |

- `points` 每项写「标签：说明」，脚本会把标签渲染成带下划线的 run、冒号后半部分渲染成普通 run。
  同页要么全部带标签，要么全部不带，不要混排。
- `figure` 是**图表对象**（`type` + 数据），不是一句配图说明。契约与按页选型见
  `references/figure-spec.md`。脚本调用 `shapes.py` 生成原生形状后插进图表槽。
  不填、或绘制失败，才退回模板的「图/表」占位——退回结果不算成品。
- 缺字段会被清空，模板里的「xxx」「1，2句话总结。」绝不会残留到成品。

## 七、脚本用法

```bash
# 1）抽取申请书正文（.docx）
python3 scripts/extract_doc.py --input 申请书.docx --out 申请书.md
python3 scripts/extract_doc.py --input 申请书.docx --headings-only   # 只看章节标题，做映射用

# 2）生成 PPT（旁白写进备注页）
python3 scripts/build_ppt.py --content content.json --out 答辩PPT-项目简称-YYYYMMDD.pptx \
        --narration-out 旁白稿-项目简称-YYYYMMDD.md
```

输出：pptx + 逐页校验报告（要点条数/字数、总结字数、旁白字数与估算时长）。
脚本仅重置被填充形状的 `txBody`，模板其余部分逐字节保留。
`shapes.py` 只有嵌申请书原图（`render_image`）和出自查预览图（`to_preview_png`）
用到 Pillow；自己画的图生成原生形状，不需要它。

## 八、脚本对模板做的调整（如实列出）

1. **封面右下角**：模板继承 18 磅等线且框只有 5.94 × 1.80 cm，投影读不清。
   脚本改为楷体 20 磅三行（报告人 / 单位 / 日期，单位行 18 磅），
   文本框改为 (21.20, 14.75) cm、11.40 × 3.35 cm，关掉自动缩放。
2. **图表槽**：自己画的图由 `shapes.py` 生成一组 PPT 原生形状，插在 `矩形 2` 的位置，
   在 PowerPoint 里可以直接点选编辑；申请书原图（`type: image`）按位图嵌入，
   PNG 写入 `ppt/media/generated_slideN.png`；两者都失败才退回文字说明（属异常，要查脚本）。
3. **正文与图表垂直对齐**：正文上沿抬到图表槽上沿，下沿收到总结框上方 0.3 cm；
   正文字号 12–18 磅、总结 12–16 磅，按对齐后的框高计算；关掉 `spAutoFit`。
4. **封面标题**：字体显式设为微软雅黑、默认 44 磅、段落居中，超长时降到 40 / 36 / 32 磅；
   页标题 28→24→20 磅。
5. **删除**：`ppt/changesInfos/`、`docProps/thumbnail.jpeg`、`_rels/.rels` 中对应关系。
6. **备注页**：模板只为第 2–15 页建了空白备注页，脚本为**每一页**都建备注页并写入旁白。
7. **自动页码**：由版式提供，页序变化后自动重排，无需处理。

## 九、改模板时的注意事项

- 槽位靠**形状名**定位（`文本框 1` / `矩形 2` / `文本框 31` / `文本框 33` / `文本框 3` /
  `文本框 6` / `标题 1` / `副标题 2` / `Text Placeholder 2`）。改名必须同步改 `build_ppt.py`
  顶部的 `SLOT_*` 常量；重命名形状后 PowerPoint 可能自动加序号，改完要回填常量。
- 蓝图页号写在 `BLUEPRINTS` 字典里；替换模板后要核对每类页的蓝图页号是否仍然对应。
- 单张幻灯片里不要出现嵌套的 `<p:sp>`（分组形状），脚本的形状扫描不处理嵌套。
