# 旁白规范（15 分钟以内）

配套 `references/content-spec.md`。旁白写到 `content.json` 的 `narration` 字段
（build 时自动写入 PPT 备注页并导出旁白稿 md）。

## 1. 总量与预算

按每分钟 200 字折算，**总字数 2600–3000 字（约 13–15 分钟），硬上限 3000 字**。
写完必须统计（check_narration.py 机械校验，超 3000 字判错误）。

默认 12 页的逐页预算（合计约 2850 字）：

| 页 | 字数 | 说明 |
|---|---|---|
| 封面 | 80–120 | 问好 + 论文题目 + 一句话定位 |
| 一.论文概述 | 320–400 | **完整一段**，照下面第 3 节的固定顺序讲 |
| 二.研究背景 | 260–320 | 沿页面逻辑链讲，落到缺口 |
| 三.研究问题 | 240–300 | 先念核心问题，再带动机示例 |
| 四.传统研究现状 | 300–380 | 每类方法：原理一句 + 不足一句 + 引用 |
| 五.核心原理 | 280–340 | 重点页：洞察 + 对应化解的不足 |
| 五.步骤页（每页） | 240–300 | 讲机制怎么工作，少念参数 |
| 六.实验页（每页） | 260–320 | 先说要回答什么问题，再讲结果与分析 |
| 七.总结 | 320–400 | 总结 + 不足与改进 + **启发必须讲透** |
| 要点回顾页 | 60–100 | 一句话 take-away 收束 + 报论文出处 +「感谢聆听」 |

方法/实验页数变化时按此单页预算增减，总量仍卡在 2600–3000。

## 2. 口吻与听众

- 讲解口吻：用「本文」「我们来看」；不写聊天腔（禁止「卡住」「对症」「说白了」「所以呢」「咱们」「呃」）。
- 听众是**学术专家 + 小白混合**：
  - 术语第一次出现给一句白话解释（如「KV 缓存——就是推理过程中间结果的缓存」），
    之后直接用；
  - 图表要讲「看出什么」而不是念数字：先说结论，再点 1–2 个支撑数字；
  - 公式不念推导，讲直觉。
- 每页开场承接上一页（「看完了背景，我们再看…」），不要每页都用同一个开场。
- 数字与论文原文逐个一致；倍数、百分比不许改动或四舍五入到别的数。

## 3. 概述页旁白的固定顺序（用户模板，必须完整）

一段话讲完，顺序固定：

1. **发表信息**：本文来自哪年、什么会议/期刊；这个会议/期刊是 xxx 方向的什么级别（CCF-x/顶会/期刊），影响力如何（录用率、规模可讲一句）；
2. **背景**：两三句；
3. **引出问题**：背景里什么矛盾引出了研究问题；
4. **已有方法原理及不足**：一两句（类别 + 共性不足）；
5. **本文方法**：为了解决 xxx 问题，本文提出 xxx，原理是 xxx，能够 xxx；
6. **实验结果**：有效，最关键的 1–2 个数字；
7. **意义**：其意义在于 xxxx。

## 4. 各页旁白要点

- **封面**：问好、论文题目（中文译名，可带英文原题）、一句话定位（「这是一篇做 xxx 的论文」）。
- **研究背景**：沿逻辑链讲，每环一两句，最后一句明确「这就带来了一个问题」。
- **研究问题**：把页面上那句核心问题完整念出来（这是全文最该被记住的一句话），
  然后用动机示例/数字把问题讲疼。
- **研究现状**：每类方法点名代表工作（「AttAcc 这类工作把 KV 缓存当作大张量静态映射」），
  讲原理 + 不足；结尾一句总括「所以还缺一个……的运行时」。
- **方法页**：原理页把「为什么以前做不到、本文怎么做到」讲透（这是专家最关心的）；
  步骤页讲机制怎么运转，配图讲（「大家看左边的图，……」）。
- **实验页**：先说这组实验回答什么问题，再讲设置一句、结果数字、分析（收益从哪来）。
- **总结页**：先一句话总结全文；再讲不足与改进（每条一句）；**最后讲启发**——
  对本领域/自己工作有什么可借鉴的思想，1–2 条，讲清楚为什么值得借鉴。
- **要点回顾页**：一句话 take-away 收束全场（呼应页面红粗词），报一遍论文出处
  （英文原题 + 会议/期刊或 arXiv 编号），最后一句「以上就是本次分享，感谢聆听」。
  不说「欢迎批评指正」这类套话。

## 5. 旁白稿 md 格式（build_ppt --narration-out 自动生成）

```markdown
# 《题目》论文总结PPT旁白稿

> 共 12 页（含封面与结束页）；按每分钟 200 字折算，须在 15 分钟内讲完。

## 第1页 封面

　　各位老师好，……

## 第2页 一.论文概述

　　（旁白正文，一段或两段，每段以两个全角空格开头）

**旁白总字数：2856 字（约 14.3 分钟）**
```

该格式与 `build_docx.py` 的方言一一对应，直接转 docx；
机械校验用 `check_narration.py`（页面连续、预算、格式、口语、数字溯源）。
