# 阶段 3：方案竞标与调研论证

**执行者**：3 个竞标写手（并行、互不通气）→ 主 agent 或裁判模型选优 → 1 个论证员。**主 agent**：同时派三案、组织选优、派论证员、核对。
**输入**：调研大纲 + 资料库（`index.md`、`阅读记录.md`、`精读记录.md`）+ 用户素材或已确认的研究思路（方法侧的事实来源）。
**落盘**：`grant-<项目简称>/03-竞标-案A.md`、`03-竞标-案B.md`、`03-竞标-案C.md`、`03-方案竞标.md`、`03-调研论证.md`。

## 第一步：三案竞标

在论文入库、阅读记录完成之后，先产出三份候选方案，由高级模型选优，以最优案为后续全部写作的基准。用户没给素材也没确认研究思路时，先停下来要，不带着空的方法槽位开标。

**怎么产生**：三个竞标写手在同一条消息里同时派（Agent 工具，general-purpose 或更强），三者互不通气、看不到彼此草稿，主对话不预设倾向。每案拿到的输入包相同：调研大纲、`02-资料库/index.md`、`阅读记录.md`、`精读记录.md`、用户素材要点。竞标必须建立在这批已下载、已精读的论文之上——方案里出现的每个数字、每篇代表工作、每条分类依据都要能回指资料库编号，凭空生成的方案作废重写。

**每案固定槽位**（任一槽位写不满的方案作废重写）：

1. **研究背景**：2–3 句，含已核验数字并标资料库编号。
2. **研究问题**：1–2 句，科学问题表述。
3. **传统研究方法**：先声明分类维度（按方法 / 按模块层次，二选一），显式分类句「按〈维度〉分为：〈A〉、〈B〉、〈C〉」；逐类先写总体原理（1–2 句，不出现具体工作名），再写原理性不足，代表工作标资料库编号。按模块层次分类时用「N 个层次 / N 个方面」，不用「N 类方法」。
4. **研究难点**：2–3 条，每条论证为什么难（原理性两难），条与条之间的逻辑关系写明白。
5. **本项目方法原理与优势**：方法原理只能取自用户素材或已确认研究思路，不得编造；优势从原理上写清与传统方法的不同。

**选优**：由高级模型（配置了更强裁判模型时用裁判模型，否则主对话担任）逐案对照五条标准评审——（1）问题描述越重要、研究意义越大越好，由背景数字与论证链衡量，不看自评措辞；（2）研究问题是科学问题，不是工程实现或系统搭建问题；（3）难点描述清楚、难点之间有逻辑；（4）传统研究分类合理、逻辑通顺，每类总体原理与不足对应得上；（5）方法创新性与意义越大越好，且能说清与传统方法的不同及优势。评审落五条标准的逐案评语与对比结论，选定一案为基准；两案相当时写出裁决理由再定一案，不折中混写成第四案。落选案确有可取之处的（某条分类、某个数字、某句难点表述），在选优记录里写明吸收项与理由后并入基准案，基准案的结构主线不变。

**落盘**：`03-方案竞标.md`（三案全文或引用路径、五条标准评审记录、选定结论、吸收项）。

## 第二步：核对精读归类

精读在阶段 2 已完成；本步确认基准案里的每篇代表工作都已精读、归类与精读记录一致。没精读过的论文不进分类、不进论证；发现基准案归类有误的，回 `03-方案竞标.md` 记录修正后再写论证。`待补全文.md` 未清空时，缺的那几篇先不写实质论断，等用户补齐后再进入。

## 第三步：撰写调研论证（论证员）

逐条回答阶段 1 的问题，以基准案为骨架展开成一份论证文档，章节固定为：

1. 研究背景与立项必要性
2. 国内外研究现状与技术进展
3. 主流技术路线的总体原理与局限性
4. 拟解决的关键科学问题与技术难点
5. 本研究的总体思路与核心方法
6. 初步创新点与先进性论证

写法要求：

- 第 2、3 章的每类现状**先写总体原理**（这类方法把问题归结为什么、靠什么核心机制成立、依赖什么前提假设），再写代表工作，每篇代表工作写完要能回扣到总体原理；最后由前提假设推出固有不足。只堆文献、没有总体原理的类别退回重写。
- 每条现状都写成"代表工作做到了什么 + 它没覆盖的具体环节"，不写"现有研究均无法……"这类全称判断。局限必须能回指到原理，而不是回指到"还没人做"。
- 分类框架、难点条数、创新方向都以基准案为准展开，不另起炉灶；创新点在这里按原理层写完，阶段 5 只做迁移。
- 技术难点取自基准案第 4 槽位并在第 4 章保持 2 或 3 条，逐条写成原理性两难并论证为什么难，不写「难度大、涉及面广」这类空话；阶段 5 只做迁移，难点条数不再增减。
- 第 4 章末画出「传统方法原理 → 不足 → 科学问题成分 → 本文方法机制 → 此前做不到、现在能做到的事」对照表，第 5 章的每个机制都能在表里找到行。
- 文档里每个实质判断都标资料库编号，保证阶段 5 写申请书时能溯源。
- 论证员写完自检：分类句里的分类名词与各节标题、第 4 章对照表的行名三处一致。

**落盘**：`03-调研论证.md`。

## 主 agent 核对

- 三案文件齐全，每案五槽位都有内容；`03-方案竞标.md` 有五条标准逐案评语与「基准案 = X」结论。
- `03-调研论证.md` 六章齐全；第 4 章对照表存在；Grep「然而|为前提」计数 ≥ 分类数。
- 分类名词三处一致（分类句 / 节标题 / 对照表）。
- 向用户汇报基准案与吸收项，请用户确认后进阶段 4。
