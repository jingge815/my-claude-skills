# 阶段 5：提炼已有工作、撰写正文、专职绘图

阶段 5 分三步串行：5a 提炼员 → 5b 写手 → 5c 画图员（写手嵌入）。**主 agent**：按序派发，5b 结束跑 `check_md.py`，5c 每图核对审计文件。
**输入**：调研论证文档 + 格式说明 + 用户素材 + 精读记录。
**落盘**：`05-已有工作提炼.md`、`05-口径表.md`、`05-申请书.md`、`figs/figN.spec.json`、`figs/figN.png`、`figs/figN.png.audit.txt`。

## 5a 提炼已有工作（提炼员）

用户给了源码或文档时，先读再写，读完落一份 `05-已有工作提炼.md`，每个模块一条，写清四件事：入口在哪个文件或函数、处理的数据对象是什么、依赖哪条编译期或配置信息、产出什么可检查物。技术路线里的机制名、步骤和数据对象只能从这份提炼里取。提炼里没有的机制，不写入申请书；素材里有但申请书用不上的，在提炼里注明「不纳入」，不悄悄丢掉。

没给素材、也没有已确认的研究思路时，停下来要，不凭文献里的方案补写研究内容。

**写手 brief 必读**：`writing-rules.md`、`writing-sections.md`、`03-调研论证.md`、`04-格式说明.md`、`05-已有工作提炼.md`、`精读记录.md`。**写手不读**：`阅读记录.md` 全文、`pdfs/`、其他阶段的草稿。

## 动笔前的文献门槛

核对一遍：正文将引用的每篇文献都有本地 PDF 全文与需求导向精读记录；`待补全文.md` 清空，或剩余条目已经用户确认可以不用全文。任何一条不满足，先补齐再动笔，不开「边写边补」的口子。

## 口径表先行（写手第一件事）

动笔前落 `05-口径表.md`：论文篇数（总数 + 各研究内容分配）、原型套数与名称、研究报告份数、每条考核指标的数值与验收口径（功能验证 / 仿真估计 / 代理预测 / 真实硬件实测）、研究周期总月数与各阶段月数、研究内容数、分类数、难点数。后文全部从这张表取数，不在各章节分别现想。`check_md.py` 的 C11 会核对正文与表的一致。

## 时态分开

对申报而言这些内容是拟开展的研究，研究内容与技术路线一律用「研究、建立、提出」写，不写「已实现、已完成」。已有进展只在「研究基础」一节如实写，并补一句「本项目在上述基础上新增〈哪几个机制〉」，新增部分必须能在研究内容里找到。不得把已有成果同时写成「已完成」和「拟研究」。

## 写作顺序

先口径表，再研究现状与需求，再研究目标，再研究内容与技术路线（图位留占位），再创新点收口，再指标、成果、周期、风险、团队，再派画图员出图并嵌入，最后写摘要。摘要最后写，是为了让它跟正文对齐。

## 图位约定（写手 ↔ 画图员的交接）

写手写正文时在每处图位写三样东西，不画图：

```markdown
　　……总体研究框架如图 1 所示。

<!-- 图规格 fig1
类型: framework | 布局: column | 标题: 〈对象〉总体研究框架
顶带: 〈输入/科学问题，每项一个框〉
分组: [研究内容1 〈名〉: 1.1 〈模块〉, 1.2 〈模块〉, 1.3 〈模块〉; 研究内容2 …]
边: [研究内容1→研究内容2 〈标签〉; …]
底带: 〈验证载体〉
术语来源: 三、研究内容 总起段 + 各项第 3 段
-->
![](figs/fig1.png)
图1 〈对象〉总体研究框架
```

主 agent 把每个 `<!-- 图规格 figN … -->` 块连同正文相关段落路径一起交给画图员；画图员产出 `figs/figN.png` 后写手核对图内术语与正文一致、`![](figs/figN.png)` 路径正确即完成嵌入。**最终稿里不得残留 `<!-- 图规格 -->` 注释块**（HTML 注释不进 docx，但 md 作为交付物要干净，5c 结束时删除）。画图员的工作规范见 `figures.md`。

## 写手 brief 的完成条件

- 格式说明里的每个章节都有内容；模板强制栏目无遗漏。
- `check_md.py --allow C03,C04,C18` 退出码 0（C03 ASCII 图、C04 图片存在、C18 图片分辩率三项在 5c 之前允许未过，仍会打印出来供画图员参考；其余全部通过）；C12 分类命名一致、C14 风险措辞、C15 周期结构、C16 目标结构四项零警告。
- 图规格块数量 = 格式说明要求的图数，每块含类型、标题、分组、边、术语来源。
- 回报：各章完成情况、图位清单、待用户确认项（口径表中标「待确认」的指标）。

## 主 agent 核对（5b 结束）

- 跑 `check_md.py --allow C03,C04,C18`，看退出码与 C11–C16 的警告。
- 抽查研究现状任一类别段：第 1–3 句不出现具体工作名、转折句「然而上述工作均以…为前提」存在。
- 抽查研究目标总目标段：含「分为」与关系词。
- 抽查研究周期首段：含「思路」与「分为」。
- 抽查风险节：每条有控制 + 兜底，末句「总体可控」。
