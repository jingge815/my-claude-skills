# 全文写作通则

写手与校对员必读。一旦有了模板或格式说明，章节划分、标题层级、字数、是否允许分点全部改由模板决定，本文件只保留模板没有规定的条目。

本文件规定的是套路，不是内容。所有「第 N 句」里的句子都是功能槽位，写的时候换成调研论证和用户素材里的事实，不得把槽位说明原样抄进申请书。

## 标题与段落体例

1. **标题层级**：`一、` → `（一）` → `1．`（全角点）→ `1.1`。markdown 工作稿用 `##`/`###`/`####`/`#####` 承载这四级，docx 构建时按层级映射字体字号；最终正文不出现 markdown 符号。
2. **段落体例**：正文全部是连贯段落。禁止分点列项，禁止出现「核心问题」「核心目标」「技术方案」「处理步骤」这类小标题式提示语。逻辑关系用陈述句衔接。每个正文段落段首空两个全角空格（两个汉字位）；标题、图注与表格单元格不缩进。模板或格式说明另有规定的从其规定。
3. **段落长度**：单段不超过 400 汉字（指标段不超过 250）。超长段拆成「总说 + 分说」两段，不靠删内容硬压。

## 句式

4. **句序**：每段第一句点明本段功能，第二句给依据或承接，第三句起展开，最后一句收束到本项目。不写「众所周知」「随着技术的发展」这类无出处的起句。
5. **统计数字句**：基数与占比指代同链，如「76% 的开发者……，其中 82%……」，不在句中更换指代对象（如写成「使用者中 82%」）。数字与单位之间不加空格以外的符号；中文数词与阿拉伯数字不混用（全文统一用阿拉伯数字，「十余款」这类约数除外）。
6. **先总后分**：凡引出两处以上的困难、目标、内容或阶段，先总说后分说。总说用一句话概括整体面貌并枚举其方面，枚举措辞与后文分说逐字平行；随后逐条展开，分说各条用「针对〈困难 i〉，研究/提出〈方法〉」起句回收总说的枚举词。总说与分说之间不插图、不换话题；缺总起或总起后没有分说，都退回补齐。
7. **研究性用词**：动词用「研究、建立、提出、揭示、刻画」，不用「实现、搭建、开发、打造」充当研究内容的谓语。系统、平台、软件栈只作为验证载体，在每条内容里出现不超过一次。
8. **指代**：「其」「该」「上述」每处都要有唯一的先行词，且先行词在同桌或前一句内；一段内出现两个以上可能的先行词时改用名词重复。
9. **长句**：单句不超过 80 字或 3 个分句；超了拆句，不用「从而」「进而」把两层因果硬连成一句。
10. **连接词**：「然而」只用于真正的转折，「因此」只用于前句确实是原因，「从而」只用于前句确实是手段；逻辑关系对不上的连接词删掉或换成正确的。

## 分类命名一致（硬性）

11. **分类维度二选一，全篇措辞随之固定**：
    - **按方法 / 技术路线 / 机制分类** → 后文称「N 类方法」「N 条技术路线」「N 类技术路线」。这是默认方式。
    - **按模块 / 层次 / 环节 / 方面分类**（如「编程接口层、系统资源层、应用编排层」） → 后文称「N 个层次」「N 个方面」「N 类研究」「N 个环节」。**不得**称「N 类方法」「N 种方法」「N 条技术路线」——按模块分时，每个类别里混着多种方法，称「类方法」在逻辑上不成立，评审一眼看出分类没想清楚。
    - 分类句（「按〈维度〉，现有研究分为 N 〈分类名词〉」）、各节标题、现状收束段、研究目标总目标、研究内容总起段**五处的分类名词逐字一致**。`check_md.py` C12 会扫描维度词与分类名词的搭配，但最终以人工核对五处为准。
    - 同一篇论文横跨两类时，按「它验证什么对象、保证在什么时机产生」归类并在精读记录写明依据；归类存疑的宁可换代表工作也不硬凑。

## 篇幅口径

12. **字数**：汉字按字符计，不含标题与图注。各节给出的是上限或区间，误差不超过 10%，超出即删，不另起一段消化。多轮修订做增量—减量对账：新增内容必须配等量压缩，压缩顺序为赘语（「归结起来」「具体而言」）→ 修饰词 → 重复限定 → 低价值细节；每轮改完重新计数。字数口径动笔前确认是否含固定栏目，自检时按「论证正文」与「含固定栏目」双口径报告。

## 引用与命名

13. **引用**：背景与现状的每个实质判断句末标编号 `[n]`；同一来源全文复用同一编号；编号按正文首现顺序排列。引用格式按格式说明（默认 GB/T 7714）。
14. **科学问题名称**：名称 = 〈对象〉+〈核心科学问题〉+〈机制特征〉（如「大模型程序变换的语义保持验证与可信反馈机制」），不用「基座、平台、系统」等工程词收尾；名称里的对象词与总目标逐字一致。
15. **术语唯一**：同一概念全文只用一个词。研究内容里的机制名、图内文字、科学问题名称、摘要、指标五处术语逐字一致；不出现「正文已改、图还是旧词」。圈内行话首次出现处括号解释或换成自解释词。

## 默认章节顺序

一、概述（（一）需求分析，（二）研究现状）→ 二、研究目标 → 三、研究内容（含各研究内容及其技术路线）→ 四、预期成果与考核指标 → 五、团队研究基础和条件（模板含此栏目时）→ 六、研究周期与进度安排 → 七、风险分析与控制（模板含此栏目时）→ 八、经费方案（模板含此栏目时）→ 参考文献。摘要单列，最后写，放在正文之前。各章节写法见 `writing-sections.md`。
